This is a scaffold page from phase A0. It describes the Handbook itself, not a technical topic,
so it has no sources. The first real topic is the Wave 0 pilot (cache-aside and cache stampede).

## How content is organized

The Handbook is split into **tracks** (for example Caching or Messaging). Each track holds
**subtopic pages**, and every page follows the same template: TL;DR, why it exists, a mental
model, then deeper layers, scenarios, interview questions, a cheat sheet, flashcards and a quiz.

## The four depth levels

| Level        | What you get                                                          |
| ------------ | --------------------------------------------------------------------- |
| Fundamentals | What it is, the problem it solves, a tiny example                     |
| Intermediate | How it works inside, trade-offs, alternatives, common mistakes        |
| Production   | Configuration, failure modes, monitoring, cited numbers, checklists   |
| Staff        | Design for scale, cost, operations, defending decisions in interviews |

You can stop at any level. Start with Fundamentals and Intermediate.

## The study loop for one page

1. Read to the level you need.
2. Close the page and explain it in your own words. Note the gaps.
3. Answer the interview questions and take the quiz.
4. Add the flashcards to your revision queue.
5. Write down any doubt so it can be answered and folded back into the page.

## How to trust a page

Every non-obvious claim on a topic page links to a source. Each page shows when it was last
verified (`lastVerified`) and when it is due for review (`reviewAfter`). Anything that could not be
verified is marked **unverified** and logged, never presented as fact.
